# Research and handoff reference

Use this reference when the task includes comparative research, a moodboard record, or a designer handoff.

## Reference record

Use one row or card per source:

| Field | Requirement |
|---|---|
| Source | Brand, studio, publication, or creator |
| Direct link | First-party page or public post whenever possible |
| Consultation date | Use an unambiguous date format |
| Format | Product page, campaign, editorial, feed post, carousel, Reel, Story, or other |
| Composition | Describe only visible, verifiable decisions |
| Why it works | Connect elegance or impact to light, scale, hierarchy, material, crop, colour, or rhythm |
| Transfer | Abstract a principle that fits the commissioning brand |
| Do not copy | Identify proprietary codes, unrealistic production values, or contextual mismatches |
| Access note | Record blocked, partial, login-only, JavaScript-dependent, or otherwise limited access |

Twenty to thirty references normally support an in-depth study, but use fewer when the user asks for a lighter review or evidence quality would otherwise fall.

## Recommended document structure

1. Short diagnosis.
2. Commented reference board with direct links.
3. Transferable principles, source-specific codes, passing trends, and realistic decisions.
4. Five art-direction principles.
5. Five things to avoid.
6. Concrete photography system.
7. Content families.
8. Nine-post rhythm.
9. Designer or production handoff.
10. Decisions awaiting approval.

## Photography specification checklist

- Name the main light source, direction, softness, subject distance, diffusion, and fill.
- Limit the background and surface library so it can be repeated.
- Define wide, medium, and detail distances using both approximate measurements and subject occupancy.
- Give props a narrative function: material, scale, gesture, or occasion.
- Define white-balance intent, contrast, saturation, highlight protection, texture, and preset consistency.
- State phone lens, grid, aspect ratio, exposure, stabilisation, focus, and selection guidance.
- Preserve safe zones for intended feed and vertical crops.

## Content-family specification

For each family, include:

- role in the content system;
- sequence or structural pattern;
- minimum photography or footage required;
- maximum cover and slide text;
- when to use it;
- what it should alternate with in the feed.

## Approval boundary

Before template or production design, ask the user to approve only decisions that change the system materially, such as warmth, background set, human presence, on-image text frequency, logo frequency, content families, grid rhythm, priority occasions, and production resources.
