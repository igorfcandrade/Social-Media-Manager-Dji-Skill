## Antes de publicar

- [ ] O gancho promete o que o corpo entrega
- [ ] Uma ideia, uma chamada à ação
- [ ] Nenhuma afirmação que não se consiga provar
- [ ] Nenhum número ou condição escrito de memória — todos vieram do perfil
- [ ] Texto alternativo em cada imagem e cada slide
- [ ] Legendas revistas manualmente
- [ ] Contraste ≥ 4,5:1 (3:1 texto grande)
- [ ] Hashtags em CamelCase, dentro do limite da plataforma
- [ ] Texto fora das zonas da interface — verificado na aplicação real
- [ ] Sem marca de água de outra aplicação, sem bordas, com som
- [ ] Sem engagement bait
- [ ] Rótulo de IA, se aplicável
- [ ] Autorização escrita, se há conteúdo ou imagem de terceiros
